# ORACLE v4.4 — Interactive Archive

## Added
- Cinematic reconstruction sequence when opening a memory fragment
- Live session log with archive, trace, warning, and mode events
- System-state banners for Index, Reconstruction, Echo Scan, Fragment Lock, and anomaly review
- Fragment-aware cursor state (`LOCK ####`) and subtle cursor echoes
- More game-like blur, travel, and rotation feedback
- Reactive orbital architecture that settles when a fragment is active

## Kept unchanged
- Index view and its editorial layout
- Existing memory data and archive storage format
- Existing import/export and desktop controls

## Notes
- The reconstruction animation can be skipped by clicking it.
- The session log opens from the `SESSION LOG` tab at the lower-right.
